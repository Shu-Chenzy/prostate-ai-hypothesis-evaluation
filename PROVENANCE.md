# Provenance

Who or what produced each part of this repository.

| Component | Source |
|---|---|
| Biological question (ARSI resistance; SSTR1 as a prespecified gene) | Shu Chen |
| Discovery dataset (GSE35988) and the first differential-expression notebook | Shu Chen, written before AI-assisted revision |
| Replication cohort (SU2C/PCF 2019) and the composition/handling check | Proposed during AI-assisted development; reviewed and accepted by Shu Chen |
| Python implementation | Claude Code, directed, reviewed and revised by Shu Chen |
| Debugging and documentation | Claude Code-assisted; edited by Shu Chen |
| Model responses (`evaluation/responses_*.csv`) | Anthropic API, retained unchanged |
| Closed evaluation questions and reference labels | Generated by code from the analysis results; labels are analysis-derived, not independent biological ground truth |
| Open-question rubrics | Drafted with Claude; reviewed by Shu Chen |
| Open-question scoring | Initial scores and notes drafted by Claude; final scores and notes decided by Shu Chen |
| Biological interpretation | Shu Chen, AI-assisted |

The `rationale` and `answer` columns in `evaluation/scoring.csv` are copied verbatim from the raw responses file. Author judgements appear only in `author_score` and `author_note`.
